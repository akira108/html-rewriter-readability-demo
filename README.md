# html-rewriter-readability-demo

This project demonstrates the usage of `@akira108sys/html-rewriter-readability`, a library for extracting content with mozilla/readability algorithm in Cloudflare Workers using [HTMLRewriter](https://developers.cloudflare.com/workers/runtime-apis/html-rewriter/).

See: [https://github.com/akira108/html-rewriter-readability](https://github.com/akira108/html-rewriter-readability)

Demo: [https://readability.akira108.workers.dev](https://readability.akira108.workers.dev)
